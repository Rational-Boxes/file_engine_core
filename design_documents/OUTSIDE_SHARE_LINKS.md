# Generator for one-time for upload/download

Support to generate a URL to a file for download, with a limited number of downloads,
and a specific timeframe. For folders an upload link that allows a max number of files
to drop, and also a validity period. This allows unauthenticated external users to
receive the 'magic' link to download/upload with no additional visibility or access.

These features will be integrated as new sharing tabs on the file/folder drawer.
